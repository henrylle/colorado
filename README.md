# Curso: Amazon Bedrock

Material do curso de **Amazon Bedrock** do **Henrylle Maia**.

Aqui ficam os projetos de exemplo construídos ao longo das aulas — do primeiro
`converse` via CLI até o assistente com RAG, tools e guardrails.

## Onde fica o quê

| Pasta | Conteúdo |

| `scripts/` | os projetos de cada aula, em CLI e em Node |
| `scripts/sdk-node/` | as versões em Node, de `v4` a `v9` |
| `material-alunos/` | material de apoio em HTML e PDF |

| `apoio/` | anotações e material de referência |

# Serverless na Formação AWS: Lambda, SAM e Lambda Edge

Este documento cobre o que a Formação AWS ensina sobre computação serverless, sem
servidor para gerenciar.

## Lambda

- Ideia do serverless, Hello World, invoke
- Cobrança, monitoramento, logs, schedule
- Empacotamento e deploy
- SAM
- Serverless Framework
- xRay
- Projeto prático de migração de uma aplicação do zero para 100% serverless, tanto
  front quanto backend

## Lambda Edge

- Criando função e integrando à distribuição
- Origin Request
- Viewer Request
- Interceptando querystring

## SDK e AWS CLI

- SDK em diferentes linguagens
- AWS CLI, todo orientado a Docker: EC2, S3, SQS, ACM, Lambda, ECS e ECR

# Segurança na Formação AWS: IAM, WAF, ACM e Secrets Manager

Este documento cobre o que a Formação AWS ensina sobre segurança na AWS, incluindo
atacar e depois proteger uma aplicação real.

## WAF

- Atacando uma aplicação
- Derrubando a aplicação
- Protegendo contra o ataque

## ACM

- Emitindo certificado
- Uso com ALB
- Uso com CloudFront

## IAM

- Acesso seguro
- Roles, Policies, Users, Groups
- MFA
- ARN
- Integração com serviços, como S3
- CloudShell
- IAM Identity Center

## Secrets Manager

- Integração com RDS
- Armazenamento de dados sensíveis
- Uso prático com a BIA

## Systems Manager

- Parameter Store
- SSM
